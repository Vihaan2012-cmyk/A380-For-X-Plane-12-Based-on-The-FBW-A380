# EFB moving map (map47)

Date: 22 October 2026. A new native EFB page: a moving map with own ship, the FMS route, online traffic (VATSIM/IVAO), X-Plane AI/TCAS traffic, a precipitation overlay from X-Plane weather, navdata (airports, VOR, NDB, airways when zoomed in) and AMDB airport diagrams when zoomed in at an airport. Drawn by the same `DomDisplay` path as the rest of the native EFB (see `2026-10-22-native-efb.md`).

## 1. What exists now

- `crates/efb_map` (new, own `[workspace]`, depends on `mfd_tree`): all map logic, no plugin or X-Plane types.
  - `projection`: Web Mercator, 256 px tiles, fractional zoom 2 to 17, rotation about the screen centre (track up), `project`/`unproject`, `pan_pixels`, `zoom_about` (point under the finger stays put), `tiles(z)` covering the rotated view, antimeridian wrap, `scale_bar` (round NM or metres), `describe()` = `merc;lat;lon;zoom;rot;w;h` for the renderer and hit test.
  - `controller::MapController`: pointer down/move/up with a 6 px tap dead zone (same as the EFB plan), drag pans and drops follow, wheel 0.25 zoom levels per notch, pinch by scale, `act("map:zoom-in|zoom-out|orient|follow|layer:<id>")`, `update_own` applies follow and track up each frame. While following, wheel/pinch zoom about the screen centre so own ship stays centred.
  - `layers`: ten layers, each with a zoom range and a label zoom, user toggles (own ship cannot be turned off), airport size thresholds.
  - `declutter`: greedy, priority-ordered label placement with six candidate positions, grid-hashed collision against placed labels and symbol boxes, kept inside the view; returns placed labels and the drop count.
  - `traffic::TrafficStore`: keyed by source and id, older reports ignored, fresh/stale/expired by source, dead reckoning along track up to the stale limit, airborne only.
  - `weather`: screen-aligned sample grid (24 px cells, at most 2,400 samples), samples to levels, run-length merged rects coloured green/orange/red.
  - `amdb::parse`: the `AmdbResponse` object served by `src/oans` (`{layer: FeatureCollection}`, EPSG:4326) into classed features (runway, taxiway, apron, stand, shoulder, building, water, marking, guidance, holding) with labels from `idrwy`/`idlin`/`idstd`.
  - `scene::build_scene(viewport, toggles, input) -> Scene`: per layer a list of `mfd_tree::Shape` (svg `rect`, `line`, `polygon`, `circle`, `path` with `fill-rule: evenodd`) in screen pixels, decluttered labels, scale bar, counts. Serialisable (serde) so it can also go over the display topic as JSON.
  - Tests: `tests/map.rs`, 11 tests (projection round trip at 5 centres x 4 zooms x 4 rotations, track-up orientation, antimeridian, zoom anchor + tile cover, scale bar, declutter, layer visibility by zoom, traffic aging/extrapolation/expiry, controller gestures and actions, weather grid, scene with AMDB and navdata).
- `crates/efb_pages/src/map.rs`: `map_page(&MapPageModel) -> Node`. Tree: `div#map-content.map-page` > `div.map-stage` (`data-act=map:canvas`, `data-proj`, fixed px size) holding one absolutely stacked `svg.map-layer.map-layer-<id>` per scene layer, `div.map-labels` (absolute `span.map-lbl ...`), `div.map-ctl` (+, -, N UP/TRK UP, FOLLOW, airport ident), `div.map-scale`, `div.map-own` (GS/ALT/TRK in `home-kv` rows); `div.map-side` with `box` cards for Layers (`button.map-row` with `data-act=map:layer:<id>`, switch, "Zoom" hint when on but outside its zoom range) and Legend, plus a status line. 1 test in the module. `MapPageModel` holds only `mfd_tree` types, so `efb_pages` does not depend on `efb_map`; the glue copies `Scene` into it (fields map one to one: `layers[i].kind.id()` -> `MapVectorLayer.id`, labels, scale, counts -> status).

## 2. Style

Colours are the EFB tokens (`app/ui/index.html :root`): route and online traffic `--ok` #3ccf6e, own ship and proximate traffic `--warn` #f0b429, holding lines and heavy precipitation `--bad` #e5484d, AI traffic `--line` #9a9a9a, flown legs and stale traffic `--line-dim` #5a5a5a, airports `--accent` ring on `--bg`, airport surfaces in the `--fx-card`/`--fx-ctl` greys. Solid fills, no blur, no gradients, no shadows (diagram style rule). Precipitation is the only translucent fill (0.45). The CSS classes the page introduces (`map-*`) are not in the generated style table yet; they need entries (section 4, step 5).

## 3. Hooks (who calls what)

| Data | Source today | Hook to add (plugin side, not done here) |
|---|---|---|
| Own ship | `sim/flightmodel/position/latitude`, `longitude`, `psi`, `hpath`, `groundspeed`, `elevation`, on-ground | `efb_map::controller::OwnShip` filled each EFB frame, then `MapController::update_own` |
| Route | `crates/fms` `FlightPlan` legs (`plan.rs`), active leg index from LNAV (`fms_lnav`) | `scene::Route { points (ident, lat/lon of each leg terminator), active_to }`; discontinuities split the list (two `Route`s or skip the segment) |
| Online traffic | `crates/datalink/src/online.rs` fetches the VATSIM v3 feed and IVAO whazzup but parses only ATC (`parse_vatsim_feed`, `parse_ivao_whazzup`) | add `parse_vatsim_pilots` / `parse_ivao_pilots` (callsign, lat, lon, altitude, heading, groundspeed, cid as id) in datalink, feed `TrafficStore::ingest(source, ...)` with `t_s` = feed `last_updated`; poll at the feed's 15 s cadence only while the map page is open and the network setting (`xphfbw.atcNetwork`) is set. Read-only public feed, no credentials |
| AI / TCAS traffic | `src/mapdata/plugin.rs` reads the 64 `sim/cockpit2/tcas/targets/*` arrays each frame (`traffic::Target`) | copy targets with `flight_id` as callsign and `modeS_id` as id into `TrafficStore::upsert` (source `Ai`) once per second |
| Weather | `src/wxr/mod.rs` point store (`HashMap<(i32,i32), Point{lat,lon,level}>`, private) and `src/datalink_host.rs` `weather_fn()` (`XPLMGetWeatherAtLocation`) | preferred: `wxr::points_in(lat/lon box) -> Vec<(lat, lon, Level)>` mapped to `WxSample` (Green 1, Amber 2, Red/Magenta 3). Fallback when the radar is off: sample `weather::sample_grid(viewport).points` through `XPLMGetWeatherAtLocation` on a worker, at most one grid per 10 s, precipitation via `weather::level_from_precip` |
| Airports, VOR, NDB, airways | navdata already loaded by the plugin for the FMS; `crates/fms` `NavDb` has no area query | add a tile-keyed area query (`Viewport::tiles(z)` with z = floor(zoom) - 2 gives 4 to 16 keys); cache per `TileKey`; airport size from longest runway (GENERIC: 2 = 9,000 ft and up, 1 = 5,000 ft and up) |
| AMDB | `src/oans/mod.rs` `AmdbProvider` (`<ICAO>.json` files) | when zoom >= 13 pick the nearest airport ARP within the view, `AmdbProvider::airport_data(icao, "EPSG:4326", &[], &[])` -> `amdb::parse`, cache the last 3 airports |
| Input | EFB native input path (plan 2.2) | `data-act` on `map:canvas` routes pointer down/move/up, wheel and pinch to `MapController`; other `map:*` acts go to `MapController::act` |
| Painting | `DomDisplay` svg leaves | `map-layer` svgs need `path` with `fill-rule`, `fill-opacity` and `stroke-linecap` (svg.cpp extension already listed in the EFB plan 2.4) |

## 4. Remaining steps

1. Plugin glue module (`src/efb_map_host.rs` or in the native EFB state): owns `MapController`, `TrafficStore`, AMDB cache; builds `SceneInput` and `MapPageModel` on change or at most 10 Hz.
2. Datalink pilot parsers + fixture tests (anonymised).
3. `wxr::points_in` accessor.
4. Navdata area query in `crates/fms` (or a small spatial index in the glue).
5. Style table entries for `map-*` classes and a rail entry "Map" (needs `app/ui` capture or hand entries; not touched here).
6. svg.cpp: `fill-rule`, `fill-opacity`, `stroke-linecap` if missing; a renderer for many shapes per layer should batch by fill colour.
7. Golden check: a fixture scene (OMDB, zoom 15 and 7) rendered by `efbx` against a reference PNG.

## 5. Numbers not from FBW or a public source (GENERIC)

Zoom ranges per layer and label zooms; traffic stale/expiry 3 s/10 s (AI) and 45 s/120 s (online); proximate traffic 6 NM / 1,200 ft; weather cell 24 px, 2,400 samples, precipitation thresholds 0.1/0.4/0.75; label glyph width 7.2 px and height 14 px; wheel 0.25 levels per notch; 6 px tap dead zone (from the EFB plan); airport size runway thresholds; own-ship lead line of 2 minutes at ground speed.
