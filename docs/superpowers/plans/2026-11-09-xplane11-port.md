# A380 for X-Plane 11: the easy port

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **No agents**: this user's rule. Execute inline.

**Goal:** The A380 flies in X-Plane 11.55 with working screens and cockpit sounds. It is built from the X-Plane 12 install with one script and one plugin binary, for the least work possible.

**Architecture:** The X-Plane 12 install is the source of truth: OBJs are hand-edited there, and releases are cut from it. So the X-Plane 11 aircraft is *derived from that install* by one script, `tools/xp11/make_xp11.py`, and the converter is not touched. The script:
- copies the folder;
- downgrades the `.acf`;
- renames the lights;
- moves the screens onto the panel texture.

The same `win.xpl` runs in both simulators. At start it checks the X-Plane version, and on X-Plane 11 it does three extra things:
- registers the X-Plane 12 datarefs and commands it uses, backed by X-Plane 11 ones;
- draws XPHFBW's frames into the panel texture instead of avionics devices;
- plays cockpit sounds through its own audio output.

Everything else runs unchanged.

**Tech Stack:**
- Rust plugin `E:/fbw-int/plugin`: gnu toolchain, `--features js`, `CARGO_TARGET_DIR=E:/fbw-build/target`.
- Python 3 tools, run with `-I`.
- X-Plane 11.55r2 at `D:/Steam Games/steamapps/common/X-Plane 11`.

**Spec:** This document. It replaces `2026-10-13-xplane11-port.md`, which went through the converter, retuned the flight model on Laminar's 747 and added an installer target. Each of those three is dropped here.

## Status, 9 Nov (commit 2179984): Stages 1-3 built, not yet run in X-Plane 11

What was built differs from the tasks below in four places:
- **acf.** XP12 split XP11's `_part` array. Bodies are XP11 parts 56+, wings parts 8+, engine positions parts 0-7 and gear struts parts 85+. These slots were learned from six aircraft that ship both versions (`acf_learn.py`; `acf11.py validate` compares the result).
  - Converted back: trim ratios, hydraulic bitmasks, SFC points.
  - Computed as Plane Maker 11 does: wing rib arms.
  - Approximated: gear springs and leg lengths, with a 2.4 ft static deflection at maximum weight.
- **Panel.** One 4096 panel with plain `ATTR_cockpit`, as ToLiss does, instead of `COCKPIT_REGION`. The UVs are panel/4096. The FCU and the three RMPs are drawn at half size; every other screen is drawn at full size.
- **Clicks.** The glass has no manipulator, so a click on it is a 3D panel click. Each frame `panel_xp11::Pointer` reads `click_3d_x/y_pixels` and the Windows left button. A changed click position is a press.
- **Screen object.** `a380_cockpit_003` is shown only in outside views, as dark glass. The cockpit object draws the screens from the panel texture.

Only the shim knows X-Plane 11 dataref names. The rest of the plugin keeps asking for X-Plane 12 names.

`Src` is how an alias gets its value:
- `Scale(n, k)`: reads X-Plane 11 dataref `n` times `k`, and writes back divided by `k`.
- `Mem`: a float the shim keeps.
- `MemArr(len)`: a float array the shim keeps.
- `Arr(n)`: passes a float array through.
- `Cloud(i)`: base, tops or coverage of the cloud at the aircraft.
- `Brakes`: writes both brakes and reads the left one.
- `Doors`: sets `door_open[i] = ratio > 0.5`.

Rule for each new `D` line from Task 1: if `DataRefs.txt` (X-Plane 11) has the same quantity under another name, use `Scale(name, unit factor)`; if not, use `Mem` or `MemArr(len)`.

pub fn cloud_at(alt_m: f32, layers: &[(f32, f32, f32); 3]) -> (f32, f32, f32) {
    let live = layers.iter().filter(|l| l.2 > 0.0 && l.1 > l.0);

"""Builds A380 for X-Plane 11 from the X-Plane 12 install."""
import re, shutil, sys
from collections import Counter
from pathlib import Path

AIRFOIL = {'_afl_file_R0': '_afl_file_1', '_afl_file_R1': '_afl_file_1', '_afl_file_T0': '_afl_file_3', '_afl_file_T1': '_afl_file_3'}


def norm(key):
    return re.sub(r'/\d+', '/#', key)


def props(text):
    return [l[2:].partition(' ')[::2] for l in text.split('\n') if l.startswith('P ')]


def downgrade_acf(xp12_text, xp11_keys, defaults):
    head, _, rest = xp12_text.partition('PROPERTIES_BEGIN\n')
    body, _, tail = rest.partition('PROPERTIES_END\n')
    kept, dropped, have = [], 0, {}
    for key, val in props('\n' + body):
        have[key] = val
        if norm(key) in xp11_keys:
            kept.append((key, val))
        else:
            dropped += 1
    for key in list(have):
        m = re.match(r'(_wing/\d+/)_afl_file_[13]$', key)
        if m:
            for new, old in AIRFOIL.items():
                if m.group(1) + old in have:
                    kept.append((m.group(1) + new, have[m.group(1) + old]))
    seen = {norm(k) for k, _ in kept}
    added = [(k, v) for k, v in defaults.items() if norm(k) not in seen]
    lines = sorted(dict(kept + added).items())
    out = head.replace('1200 Version', '1100 Version') + 'PROPERTIES_BEGIN\n' + ''.join(f'P {k} {v}\n' for k, v in lines) + 'PROPERTIES_END\n' + tail
    return out, {'kept': len(kept), 'dropped': dropped, 'defaulted': len(added)}


def xp11_key_set_and_defaults(xp11_root):
    keys, values = set(), {}
    acfs = list((xp11_root / 'Aircraft/Laminar Research').rglob('*.acf'))
    for p in acfs:
        for k, v in props(p.read_text(encoding='latin-1')):
            keys.add(norm(k))
            values.setdefault(k, Counter())[v] += 1
    return keys, {k: c.most_common(1)[0][0] for k, c in values.items()}

# Stage 2: screens

All screens go into one 4096×4096 panel texture, made of 4 regions of 2048×2048. Each screen gets a rectangle in one region. `make_xp11.py` writes the layout into the aircraft as `plugins/fbw_a380_systems/xp11_panel.json`, and remaps each screen quad's UVs to its rectangle. The plugin reads the same file and draws each XPHFBW frame into its rectangle in `xplm_Phase_Gauges` (45). One file feeds both, so the two can't disagree.

Pixel budget:
- At full size the screens total ~19.5 MP. That is more than the 16.7 MP of the 4 regions.
- The packer halves the largest screens until everything fits. The RMPs and the FCU go to half size first, which brings the total to ~13.3 MP.
- IFE, FAP and HUD are left out.
